# Coding Challenges WC tool

This is my version of the [Coding Challenges wc tool challenge.](https://codingchallenges.fyi/challenges/challenge-wc)

I've written in it [Kotlin](https://kotlinlang.org) because that's what I use everyday for work and it's what I'd like to practice at.

I discovered when starting this that Kotlin now has the ability to write Kotlin scripts with no main function :eyes: 
If you have Kotlin installed (this was written in version 2.3.21) you can run this script by running `kotlin ccwc.kts <args>`
